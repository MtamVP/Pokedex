# Pokédex.io

Pokédex.io is a web-based Pokédex application that allows users to search for Pokémon and view comprehensive details about them.

## Features

- **Search with Autocomplete:** Quickly find Pokémon by name.
- **Detailed Information:** View basic info (types, height, weight), abilities, base stats, held items, and moves.
- **Evolution Chain:** See and navigate through the Pokémon's evolution stages.
- **Alternative Forms:** Explore other forms of a Pokémon.
- **Tooltips:** Hover over moves, held items, and abilities for detailed descriptions and stats.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- [PokéAPI](https://pokeapi.co/) for data

## Usage

Simply open `index.html` in your web browser to start using the Pokédex. You can search for a Pokémon using the search bar and click on the suggestions or hit search to fetch data.
